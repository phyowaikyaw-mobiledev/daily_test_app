# Daily Test Task App

A simple yet elegant Flutter app for creating, viewing, and managing daily tasks with clean code and interactive design.  
Perfect as a junior portfolio project to showcase Flutter, Dart fundamentals, and best practices for HR, tech leads, or recruiters.

---

## 📱 Features

- **Add Tasks**: Quickly create and save new tasks with title and description using a floating action button.
- **Task List**: Instantly see all tasks in an organized list, with status toggled via checkboxes.
- **Task Detail**: Tap any task to view its complete description on a dedicated detail screen.
- **Mark Completion**: Check/uncheck tasks directly in the list; completed tasks have strikethrough style.
- **Dialogs & Navigation**: Modern AlertDialog for task creation; smooth transitions (MaterialPageRoute) for easy UX.
- **Responsive Design**: Adapts nicely to different device screens.

---

## 🛠️ Tech Stack & Structure

- **Flutter**: Uses the latest stable framework and Dart language
- **Stateless Widget**: For main app and task detail screen
- **Stateful Widget**: For dynamic note/task list and state management
- **Material Design**: Modern colors, clear layout, real app UX
- **Folders & Files**:
lib/
├── main.dart // Entry point, handles app setup
├── note_list_screen.dart // Main list UI and add-task handling
└── task_detail_screen.dart// Task detail page

## 🚀 Getting Started

1. **Clone the repository**
git clone https://github.com/phyowaikyaw-mobiledev/daily_test_app.git
cd daily_test_app

2. **Install packages**
flutter pub get

3. **Run the app**
flutter run
